# ELFACYEL MUSIC

**Independent Sound. Global Vision.**

**ELFACYEL MUSIC** is an independent record label and music company from Algeria, founded around artist **ELFACYEL** with a long-term framework for independent artists, original productions, and global reach.

## Core Principles
* **Artist Ownership:** Masters remain with the artist under clear, transparent written agreements.
* **Creative Identity:** Respecting authentic voices, artistic direction, and original sound.
* **Global Ambition:** Connecting Algerian music and independent talent with listeners worldwide.

## Website Structure
* `index.html` — Tri-lingual (`EN` / `FR` / `AR`) website structure and sections (`About`, `Artists`, `Releases`, `Services`, `Contact`).
* `style.css` — Black, white, and gold visual identity and responsive layout (including mobile and `RTL` Arabic support).
* `script.js` — Language switcher (`EN` / `FR` / `AR`) and mobile navigation handling.
